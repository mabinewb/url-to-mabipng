# 마비노기 QR 그림대화 생성기

기존 그림대화 PNG 파일에서 zTXt 메타데이터를 읽어와, URL과 라벨을 포함한 2bit PNG 그림대화 파일을 생성합니다.

## 사용 방법

1. `index.html`을 브라우저에서 열기
2. 기존 그림대화 PNG 파일 업로드
3. URL과 라벨 입력
4. 미리보기 확인 후 "그림대화 파일 생성" 클릭
5. 다운로드 링크를 통해 PNG 저장

## 특징

- 2bit PNG 생성
- QR 코드 포함
- zTXt 메타데이터(authid, author) 유지
- 라벨 텍스트 위치 및 정렬 자유 조정
- 다운로드 파일명 자동 생성
